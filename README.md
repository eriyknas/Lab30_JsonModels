## Таблица атрибутов JSON
| Атрибут / настройка | Что делает | Пример |
|--------------------|------------|--------|
| `[JsonPropertyName("name")]` | Задаёт имя поля в JSON | `"name"` вместо `"Name"` |
| `[JsonIgnore]` | Поле не попадает в JSON | Пароли, внутренние поля |
| `PropertyNamingPolicy.CamelCase` | Все поля в camelCase | `"realName"` вместо `"RealName"` |
| `JsonStringEnumConverter` | Enum как строка | `"Marvel"` вместо `0` |
| `WriteIndented = true` | JSON с отступами | Для удобства при разработке |
## Главные выводы
1. 
Сериализация — процесс преобразования C#-объекта в JSON-строку для передачи по сети.  
Десериализация — обратный процесс: JSON-строка → C#-объект.
2. 
[JsonIgnore] исключает поле из JSON-ответа клиенту.
Реальный пример: хранение пароля или внутренних заметок разработчика
3. Когда enum сериализуется как строка, клиент получает "universe": "Marvel". Сразу понятно, о какой вселенной идёт речь. Код становится самодокументируемым.
4. После добавления PropertyNamingPolicy.CamelCase изменился формат имён всех свойств в JSON-ответе.
